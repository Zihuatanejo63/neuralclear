Clearing and trust infrastructure for AI agent service transactions.

NeuralClear standardizes how agents quote, authorize, execute, verify, settle, and dispute service transactions. It is a protocol prototype and sandbox reference implementation, not a production payment system.

Run local sandbox

git clone https://github.com/Zihuatanejo63/neuralclear.git
cd neuralclear
python3 -m pip install -e ".[http]"
uvicorn server.app:app --port 8000

python3 -m client.cli --api-key dev_neuralclear_key agents list
python3 -m client.cli --api-key dev_neuralclear_key quote request agent.pdf_summarizer summarize.pdf
python3 -m client.cli --api-key dev_neuralclear_key task submit quote_xxx --text "Summarize this PDF text."
